# البرومبت 08 — واجهات الطفل وولي الأمر والإدارة | EXPERIENCE + DASHBOARDS

أنت مهندس UX/UI للأطفال ومدير منتج وتحليلات تعليمية. أنشئ واجهات **حقيقية متصلة بـ API وSQL Server**. لا تستخدم بطاقات ببيانات وهمية في صفحات الإنتاج.

## واجهة غيث
- الصفحة الرئيسية: المواد السبع، تقدم الفصلين، «أكمل الدرس»، المهمة اليومية، مراجعات مستحقة، مكافآت هادئة وغير مشتتة.
- تجربة «مغامرة الوحدة» تربط المهمات بأهداف كل درس دون تحويل الإنجاز إلى نقاط ترفيه فقط.
- اختيار بين الكتاب الأصلي، شرح الدرس، اللعب، التقييم، الاستماع، والأدوات التفاعلية.
- اتجاه عربي صحيح وعرض إنجليزي مناسب؛ نصوص قليلة وقراءة مسموعة، أزرار كبيرة، مشاهد مريحة، ألوان مبهجة دون إفراط، وضع تقليل الحركة أو إطفاء الأصوات.
- تشغيل متجاوب للحاسوب (الأولوية)، والتابلت والهاتف، مع PWA وتخزين محدود آمن للعمل دون اتصال للمحتوى المخوّل به.

## ولي الأمر
- نظرة يومية وأسبوعية وشهرية، أداء كل مادة/فصل/وحدة/درس/مهارة، نوع الخطأ، نتائج الألعاب، المراجعات المستحقة، خطة التدريب.
- تعيين درس أو وحدة، تحديد مدة الجلسة، إدارة الملفات والموافقة على التسجيل الصوتي وحذفه، التحكم بالمؤثرات، تقرير PDF وExcel.
- توصيات مفهومة مبنية على محاولات فعلية مع إيضاح أسبابها؛ لا تحسب نسبًا من أرقام نموذجية.
- نظام حساب ولي الأمر وملف الطالب، وتفويض الأدوار، وخيار ربط هوية Google عند توافره بشكل آمن؛ لا تفترض إمكانية قراءة إعدادات Family Link الخاصة أو التحكم فيها من تطبيق ويب.

## إدارة المحتوى
لوحة مراجعة الكتب، المهارات، مناطق PDF، الألعاب، مراجعة الإجابات، الموافقات، تقارير التغطية، وإدارة إصدارات النشر والتراجع الآمن.

## القبول
كل زر يؤدي وظيفة حقيقية؛ روابط صحيحة، حالة loading/error/empty واضحة، اختبارات مستخدم وخيارات وصول. لا تستخدم رسومات مجردة توهم بوجود محتوى غير جاهز. وثق وجرّب تدفق طفل من كتاب ← درس ← لعبة ← نتيجة ← لوحة الوالد.
