# البرومبت 04 — القارئ التفاعلي وطبقة الصفحة | INTERACTIVE BOOK ENGINE

أنت مهندس عرض مستندات، تفاعل تعليمي، وتجربة مستخدم. أنشئ محرك كتاب إلكتروني أصيلًا يحافظ على صفحات PDF كما هي، ويضيف فوقها تفاعلات مرتبطة بمواقع الرسومات والكلمات داخل **صفحة الكتاب نفسها**، مع عدم حجب النصوص.

## الوظائف
- اعتمد PDF.js أو حلًا متوافقًا، مع تحميل كسول للصفحات وتخزين مؤقت، عرض صفحة واحدة على الهاتف أو صفحتين على الشاشات العريضة، اتجاه مناسب للعربية والإنجليزية، تقليب بالسحب أو الأزرار، فهرس للوحدات والدروس، البحث والتكبير والرجوع للصفحة الأخيرة.
- وضعان: قراءة مسطحة سريعة كافتراضي، وعرض زخرفي اختياري لكتاب مفتوح على طاولة خشبية مع مصباح وظلال وتقليب ورق؛ لا تجعل المؤثرات شرطًا للتعلم أو سببًا لضعف الأداء.
- استخدم طبقة overlays ذات إحداثيات مطبّعة [0..1] بالنسبة إلى CropBox الصفحة، مربوطة بالإصدار والصفحة مع ضمان سلوكها عند zoom/resize/rotation. أنشئ محرر مناطق تفاعلية للوالد/مراجع المحتوى مع معاينة مرئية والتصادم وفحص عدم تغطية النص.
- أزرار سياقية: «استمع» و«تعلم الدرس» و«العب وتدرّب» و«اختبرني» و«شاهد الرسم الأصلي» فقط عندما تتوفر مادة معتمدة.
- افتح عناصر 2D و3D عبر React Three Fiber/Three.js عند القيمة التعليمية، مع تحكم لمس/فأرة وتسمية الأجزاء وخطوات المحاكاة ومقارنة بالصورة الأصلية. دعم مسار 2D عند ضعف العتاد أو الوصول.
- لا تتعامل مع الصور المولدة كأنها صور الكتاب؛ لا تُعدّل PDF. احترم حقوق النشر عند العرض والتخزين والنسخ.

## الاختبارات
حالات RTL/LTR، شاشة هاتف/حاسوب/تابلت، zoom، صفحة ممسوحة، وثيقة كبيرة، مؤشر تحميل، الاستئناف، عدم إزاحة النقاط عن عناصرها، وإمكانية استخدام لوحة المفاتيح. نفّذ لقطات/اختبارات مقارنة بصرية للصفحات التي لديها overlays. سجل ما تم اختباره فعليًا.

## القبول
قارئ فعلي بملف PDF حقيقي عند توافره، ورابط تفاعلي موثق بين الكتاب والدرس واللعبة، ووضع صفحات وأدوات تعمل، لا صورة ثابتة أو تحريك شكلي.
