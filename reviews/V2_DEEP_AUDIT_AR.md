# مراجعة V2 العميقة — عالم غيث التعليمي

## خلاصة مستقلة
- جودة الرؤية التربوية: 8.5/10.
- جاهزية تنفيذ المشروع بالكامل دون مراجعة بشرية: 5.5/10.
- الجاهزية بعد V3: **تحسن ملموس في الضبط والاستئناف؛ ولكن لم يُختبر Claude Code الفعلي ولا بُني التطبيق بعد**.

## المخاطر المفصلة وترتيب معالجتها
| معرف | الخطورة | نتيجة فحص V2 | ما أصلحه V3 أو ما لا يزال مطلوبًا |
|---|---|---|---|
| R-01 | حرجة | `tasks/queue.json` يحتوي مهام من نمط «إكمال جميع كتب الرياضيات»، وهي Epics لا مهام ذرية | عقد V3 يفرض تقسيمًا لكل كتاب/وحدة/درس/مهارة مع معايير قبول وأدلة؛ التنفيذ الفعلي لهذا التقسيم مسؤولية الوكيل بعد جرد الكتب |

| R-03 | حرجة | ملف دليل على القرص مع `status: PASS` قد ينجح فحص البنية دون إثبات اختبار فعلي | V3 يشترط قبولًا بشريًا خارجيًا من مشغّل النظام، ويصرح بأن الفحص البنيوي ليس اختبارًا تربويًا كاملًا. يجب تنفيذ اختبارات API/DB/E2E/مراجعة تعليمية فعلية |

| R-05 | عالية | `permission_denials` لا تمنع وصف الدورة بالنجاح صراحة | V3 يصنّف رفض الصلاحية فشلًا، مع تسجيله |

| R-07 | عالية | لا يوجد تعريف تمهيدي واضح لمستوى الطفل قبل التدريب المكثف | V3 يفرض Baseline Assessment قصيرًا في الرياضيات والإنجليزية وخطة مهارات علاجية غير تشخيصية |

| R-09 | عالية | النص لا يمنع بوضوح التعامل مع تعليمات داخل مصادر PDF/ويب على أنها أوامر للوكيل | V3 يعامل المصادر غير موثوقة تعليماتيًا، ويحظر تنفيذ توجيهاتها |
| R-10 | عالية | سياسة التعاون لا تحدد تسليم/دمج العامل بدقة | V3 يفرض مداخل/مخارج/ملفات مملوكة/اختبار ومراجعة دمج لكل عامل |
| R-11 | متوسطة | الحد اليومي 8 دورات، وبحد إنفاق تقديري للدورة، ليس «عملًا غير منقطع» | V3 يحتفظ بسقوف السلامة ويشرح الاستمرار المشروط، وإيقاف استهلاك الحصة عند غياب تقدم؛ لا يَعِد بإنجاز زمن غير مضمون |
| R-12 | متوسطة | سجل stdout قد يحتوي نصوصًا أو بيانات تتعلق بالمشروع بترخيص مستخدم عام | V3 ينشئ سجلات بعمليات لها umask أكثر تقييدًا (0600 عادة) |

| R-14 | متوسطة | عدم الفصل الكافي بين الإجابات الآلية والاعتماد البشري للمحتوى | V3 يفرض قواعد اعتماد بشرية خاصة بالمصادر الحساسة مع توثيق المراجع |
| R-15 | متوسطة | المتطلبات التقنية مدونة لكن اختبار النسخ والاستعادة والخدمة الفعلية لم ينفذ | ما يزال شرطًا للإغلاق النهائي، وليس مثبتًا بحزمة مدير المشروع |

## ما اختُبر بالفعل
- اختبارات Python المحلية الخاصة بملفات الإدارة (10 اختبارات في V3)؛ نتائجها موثقة عند التسليم.
- نجاح بناء/تحليل ملفات Python بلا أخطاء تركيبية.
- التحقق البنيوي النهائي يرفض إعلان إكمال تطبيق لم يُبنَ.

## ما لم يُختبر
- تشغيل Claude Code على جهاز المستخدم أو اشتراكه.
- اختبار تنفيذ بناء ASP.NET Core + React أو تطبيق EF Core Migration.
- جرد الكتب الرسمية وإدخال كل المناهج.
- صحة الألعاب والنتائج التعليمية على الأطفال أو تجربة غيث الفعلية.
- التشغيل الدائم بعد إعادة تشغيل نظام المستخدم، أو بيانات API/اشتراك فعلية.
