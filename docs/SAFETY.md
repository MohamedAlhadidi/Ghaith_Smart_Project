# ضوابط مشغّل العمل المستمر

1. لا ترفع صلاحيات أو تستخدم --dangerously-skip-permissions تلقائيًا.
2. استخرج الملفات داخل مستودع مشروع منفصل، وانقل نسخ المناهج اللازمة إليه فقط مع مراعاة الحقوق.
3. لا تحفظ مفاتيح API أو كلمات المرور في المستودع؛ استخدم متغيرات البيئة وسجل اعتماد خارج المشروع.
4. لا تربط بيانات المؤسسة أو حساب الطفل بمكونات غير مراجعة.
5. راقب الاستهلاك: إعدادات الموازنة الافتراضية: 2 دولار تقديريًا لكل دورة مع حد يومي محافظ 12 دولارًا للحجز و8 دورات يوميًا كحد للعدد، مع ملاحظة أن الفاتورة الفعلية وحدود الاشتراك قد تختلف.
6. عند توقف صلاحية اعتماد أو فقدان مواد المناهج يسجل المدير العائق ولا يختلق المحتوى.
7. توقف الآلة أو إغلاق الخدمة يوقف العمل؛ systemd يعيد التشغيل فقط إذا قُيّم واستُخدم على جهاز المستخدم.
8. لا تفترض أن النتائج صحيحة لمجرد نجاح فحوص الشكل؛ يلزم مراجعة محتوى الألعاب تربويًا واختبار تجربة الطفل.

9. الإصدار V4 يتطلب Sandbox فعليًا لفصل أوامر Bash عن ملفات المستخدم. فحص `.claude/settings.json` وحده لا يثبت نجاح العزل على جهازك؛ اختبر `claude /sandbox` أولًا.
