# نطاق المشروع V4
- الصف: الثاني الأساسي بسلطنة عُمان، الفصلان الأول والثاني للعام الدراسي 2026/2027.
- المواد السبع: الرياضيات، الإنجليزية، «أحب لغتي»، العلوم، «ديني حياتي»، الهوية والمواطنة، تقنية المعلومات.
- المشمول: كتب الطالب والنشاط والأجزاء وSounds and Spelling حسب المقرر الفعلي.
- المستبعد: الفنون والبدنية والموسيقى والمقررات الخارجية؛ أدلة الأهل والمعلم مراجع مساندة وليست مواد طفل.
- المصدر: طبعات الكتب الفعلية مع SHA256 وحقوق الاستخدام وأرقام صفحات PDF والمطبوعة.
- الرياضيات والإنجليزية: ألعاب كثيفة متعددة الآليات وقياس تأسيسي ومراجعات متباعدة، دون إرهاق الطفل.
- اكتمال المشروع مشروط بتغطية baseline معتمدة مستقلة ونشر واختبارات وقبول بشري؛ لا يكفي ملء مصفوفة يكتبها الوكيل وحده.
